# Motion Storyboard — Reels #1

Раскадровка построена в визуальном языке `MOTION_STYLE_GUIDE.md`. Формат 1080×1920, 30fps, 9:16, Reels. Финальная сборка: моё видео с лицом сверху, motion design снизу.

Тайминг восстановлен по паузам в аудио исходного видео (`ffmpeg silencedetect`) — точность ±0.1–0.3с. Исходный файл субтитров содержит только один общий диапазон `0:00–0:34` на весь текст, без пофразовых таймкодов, поэтому более точного источника нет. При наличии точного SRT/VTT с таймкодами по репликам таблицу нужно пересобрать.

Ничего не меняет смысл или порядок исходной реплики. Драматургия (light/dark, поворот, payoff) — это тональность подачи уже сказанного, не новый сюжет.

Правила:
- Ничего важного не заходит выше y=1056 или ниже y=1750.
- В нижних 2/3 motion-зоны крупная графика не заходит правее x=880 (запас под правую панель Reels — like/comment/share).
- Ни один элемент не мельче 130px (слот D) — самый важный элемент (3 канала, слот C) — самый крупный, 190px.

## 2. Motion System (сквозные приёмы)

1. **Punch Word Pop-In** — связка: fade+slide-up 12px, stagger 60–80мс, power2.out. Панч-слово: scale 92%→100% + red fill, задержка 80мс, power3.out. Уход: hard-cut на смену сцены, либо fade+scale-down 150–200мс power2.in.
2. **Scene Flip (Light↔Dark)** — смена фона всей motion-зоны синхронно с началом новой сцены, hard cut, без кроссфейда.
3. **Hero Object Reveal** — scale 0%→100% + въезд с ближайшего края, 300–400мс, power4.out.
4. **Chain/Flow Connector** — линия рисуется через stroke-dashoffset, 250–350мс, power2.inOut, стартует когда оба конца на месте.
5. **Repeating Icon Pattern Drift** — фоновый паттерн, continuous parallax ~6–8px/сек, без входа/выхода.
6. **Counter/Callback Tag** — pop+settle, scale 110%→100%, power2.out, 200мс.
7. **Dock-transition** (частный случай Hero Object Reveal, используется только в финальной цепочке E) — уже показанный hero-объект сжимается 220px→130px и смещается в слот D за 200мс, power2.inOut, освобождая слот H под следующий элемент, вместо того чтобы исчезать или уменьшаться до нечитаемого размера.

## 3. Текстовая политика

Текст — только на ключевых смыслах: тезис, метрика, панч поворота, payoff, либо там, где графика сама по себе неоднозначна (иконка нуждается в слове-подписи). Текста нет там, где смысл уже читается по графике (логотипы Telegram/VK самоочевидны) или фраза — чисто связка (сцена держится без нового элемента).

| Есть текст | Почему |
|---|---|
| «одна и та же **задача**» | тезис ролика |
| «**рассылки**» | иконка-конверт неоднозначна без слова |
| «**целый день**» | конкретная метрика |
| «**реально долго**» | смысловой панч боли (один акцент, не два) |
| «не занимает... **столько времени**» | ядро поворота |
| «**голосовое**» | иконка волны/bubble неоднозначна без слова |
| «**систему**» | иконка шестерёнки/чипа неоднозначна без слова |
| «**готовый текст**» | панч payoff'а (три канала уже видно по иконкам) |

| Текста нет | Почему |
|---|---|
| «например, у вас прямой эфир» | связка, сцена держится без нового элемента |
| «телеграм», «ВК» | логотипы самоочевидны |
| «Сейчас покажу, как.» | несёт курсор-клик |
| outro | freeze уже собранной сцены |
