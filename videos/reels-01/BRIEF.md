## Intent

Motion-design слой (без исходного видео с лицом) для Reels экспертки: боль "писать один и тот же текст отдельно под рассылку/Telegram/ВК занимает целый день" → поворот "у меня это не занимает времени" → механизм "голосовое → система → готовый текст сразу для всех трёх каналов". Финальная сборка (видео с лицом сверху + этот motion снизу) происходит позже в CapCut, вне HyperFrames.

Весь креатив уже согласован с пользователем в отдельных документах вне этого проекта, до его создания:

- `../../MOTION_STYLE_GUIDE.md` — визуальный язык (палитра, типографика, композиция, ритм) — brand truth, см. `design.md` в этом проекте.
- `../../MOTION_STORYBOARD.md` — утверждённая посекундная раскадровка, сетка кадра, motion system, текстовая политика. Это единственный источник сцен для сборки — не добавлять сцены/текст/CTA сверх него.

storyboard: no потому что раскадровка уже прошла review-цикл с пользователем вручную, до захода в HyperFrames — повторный проход через Studio-board не требуется.

## Notes

- НЕ встраивать исходное видео с лицом в этот рендер — только motion-слой.
- Верхняя часть кадра (0–1000px из 1920) визуально спокойная, под будущее видео с лицом — ничего смыслового туда не помещать.
- Callback с 3 иконками каналов — ровно 2 появления (интро + payoff), не чаще.
- Текстовые акценты — только на утверждённых в раскадровке словах, не превращать в постоянные субтитры.
- Hard-cut между light/dark сценами, без кроссфейда (см. design.md).
- Ничего мельче 130px (докованные иконки); payoff-ряд каналов — 190px, самый крупный смысловой элемент ролика.
